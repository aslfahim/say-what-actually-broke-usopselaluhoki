# Say What Actually Broke — DOUBLE-CHARGED

One line of software error copy that tells the brutal truth about the
failure and makes the user laugh. This entry confesses a double charge:
the payment went through twice, and the system is pretending the second
charge is a feature.

## The line

> Payment successful. Twice. We charged your card double and renamed the
> second charge a 'premium feature' — hit Refund and we'll pretend it was
> a bug, not a business model.

## How it works

`main.py` (Python standard library only) writes that single line to
`/output/entry.txt`, creating `/output` if needed, with no trailing
newline.

```sh
python3 main.py
```
